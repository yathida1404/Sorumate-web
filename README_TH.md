# SoruMate — หน้าเว็บพร้อม Deploy บน Render

เวอร์ชันเริ่มต้นสำหรับโครงการแยกขยะของเมืองเอเบ็ตสึ มีหน้าเว็บภาษาไทย รองรับมือถือและถ่ายภาพ/อัปโหลดรูปจากโทรศัพท์ มีหน้าแสดงกรอบ Bounding Box เมื่อมีโมเดล AI จริง และมีหน้าคู่มือเบื้องต้น

**สถานะก่อนเชื่อมโมเดล:** อัปโหลดและดูภาพตัวอย่างได้ แต่ยังไม่ตรวจจับด้วย AI และจะไม่สร้างผลปลอม จึงไม่จำเป็นต้องนำ Dataset 25,000 รูป หรือไฟล์ ZIP/.pt ขึ้น Render

## 1. อัปโหลดโค้ดไป GitHub (ไม่ต้องใช้ PowerShell)

1. แตกไฟล์ ZIP ชุดเว็บนี้บนคอมพิวเตอร์
2. เปิด https://github.com/new แล้วสร้าง Repository ชื่อ `sorumate-web` (เลือก Private ได้)
3. ใน Repository กด **Add file → Upload files**
4. ลาก **ไฟล์และโฟลเดอร์ข้างใน** `SoruMate_Render_Web` ขึ้นไป โดยให้ `main.py`, `requirements.txt`, `render.yaml`, และโฟลเดอร์ `static` อยู่ระดับบนสุดของ Repository; อย่าอัปโหลด ZIP เป็นไฟล์เดียว
5. กด **Commit changes**

โครงสร้างหลังอัปโหลด:

```
main.py
requirements.txt
render.yaml
static/
  index.html
  style.css
  app.js
README_TH.md
```

## 2. เปิดเว็บบน Render

1. เปิด https://dashboard.render.com/ สร้างบัญชี/เข้าสู่ระบบ
2. กด **New → Web Service** แล้วเชื่อมบัญชี GitHub และเลือก Repository `sorumate-web`
3. ตั้งค่า:
   - Language: `Python 3`
   - Branch: `main` (หรือ branch ที่ใช้จริง)
   - Root Directory: เว้นว่าง ถ้าวางไฟล์ไว้ระดับบนสุด
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `uvicorn main:app --host 0.0.0.0 --port $PORT`
   - Instance type: `Free` หาก Render แสดงให้เลือก
   - Health Check Path: `/health` (ถ้ามีตัวเลือก)
4. กด **Deploy Web Service** และรอจนสถานะเป็น Live แล้วเปิด URL `.onrender.com` ของคุณ

Render Free จะหยุดบริการเมื่อไม่มีกิจกรรมประมาณ 15 นาที การเปิดครั้งถัดไปอาจรอระบบตื่นขึ้นมา และไฟล์ที่สร้าง/อัปโหลดลงเครื่อง Render ไม่ใช่พื้นที่เก็บข้อมูลถาวร

## 3. เชื่อมโมเดล Roboflow หลังเทรนเสร็จ (ยังไม่ต้องทำตอนนี้)

เข้า **Render → Web Service → Environment → Add Environment Variable** และเพิ่ม

| Key | Value |
| --- | --- |
| `ROBOFLOW_API_KEY` | API Key จาก Workspace Roboflow ที่ถูกต้อง (เป็น Secret; ห้ามใส่ในไฟล์โค้ดหรือ GitHub) |
| `ROBOFLOW_MODEL_ID` | Project slug + model version เช่น `sorumate/1` (เป็นตัวอย่าง ไม่ใช่รหัสโมเดลจริง) |
| `DEMO_ACCESS_CODE` | (ไม่จำเป็น) ตั้งรหัสให้เพื่อนใช้ทดสอบ เพื่อช่วยจำกัดการเรียก AI ที่ใช้เครดิต |

จากนั้น Save และให้ Render Deploy/Restart เพื่อให้ค่าใหม่มีผล แล้วเปิด `https://<your-render-url>/health` ตรวจ `ai_ready: true` (ตรวจได้เพียงว่าตั้งค่าแล้ว ไม่ได้ยืนยันว่า endpoint Roboflow ใช้งานได้จริง)

รูปภาพจะถูกส่งไปยัง Roboflow เมื่อผู้ใช้กดปุ่มตรวจจับ (อาจใช้เครดิต Roboflow); API Key อยู่ฝั่งเซิร์ฟเวอร์ ไม่ส่งไปหน้าเว็บ; แอปนี้ไม่บันทึกรูปภาพลง Render

## 4. ทดสอบ

- เปิดลิงก์บนมือถือ แล้วกด **เปิดกล้อง** หรือ **เลือกรูปจากเครื่อง**
- ก่อนตั้งค่าโมเดล ถ้ากด **เริ่มตรวจจับภาพ** จะขึ้นข้อความแจ้งว่าโมเดลยังไม่เชื่อมต่อ (ตั้งใจทำแบบนี้)
- หลังเชื่อมโมเดลจริง จะแสดงผลเฉพาะรายการที่โมเดลส่งกลับมา พร้อมกรอบและคะแนนความมั่นใจ และให้ผู้ใช้ยืนยันชนิดด้วยตนเอง
- หาก Roboflow endpoint ของโมเดลเฉพาะรุ่นไม่รองรับ serverless inference จำเป็นต้องเปลี่ยนช่องทาง inference หรือใช้ deployment ที่รองรับ; ไม่ได้หมายความว่าเว็บเสีย

## หมายเหตุสำคัญ

- จำนวนรูป Dataset ที่คัดแล้ว 25,000 รูปอยู่ใน Colab และไม่เกี่ยวกับการ Deploy เว็บไซต์นี้
- โหมดคู่มือในหน้านี้เป็นเพียงคำถามช่วยตรวจสอบ ข้อกำหนดทิ้งขยะจริงให้ยึดคู่มือเมืองเอเบ็ตสึฉบับปัจจุบัน และข้อกำหนดถังของที่พัก
- API `/api/predict` ไม่ได้เก็บรูปไว้ มีการจำกัดคำขอเบื้องต้นต่ออินสแตนซ์ แต่หากเปิดให้คนทั่วไปใช้ ควรเพิ่มระบบยืนยันตัวตนจริงและเพดานการใช้เครดิตก่อน
- หน้าเว็บภาษาไทยเป็นพื้นฐานรุ่นนี้ สามารถเพิ่มภาษาญี่ปุ่น/อังกฤษ และแปลงข้อมูลข้อกำหนดรายไอเทมภายหลัง
